# The Kruegers Wedding Website
A custom wedding website for Cole and Bridget, created for my GIT 480 senior project.

## Project Overview
This will be a responsive, mobile first, multi page website where guests can read our story, see photos, learn about the wedding weekend, and RSVP.

The Assignment 3 and 4 high fidelity wireframes in figma are the main design reference. 

## Planned Pages
- Home
- Our Story
- Gallery
- Registry
- Details
- Contact
- RSVP

## Tools
- HTML5
- CSS3
- JavaScript
- VS Code and Live Server
- GitHub Desktop and GitHub
- Back end materials have not been fully planned and will be updated later. 

## Typography (from google fonts)
- Montserrat: body text, nav, and buttons
- Bodoni Moda: headings
- Pinyon Script: script accents and titles
- Cormorant Garamond: small details

- Added home page html and styles that can be reused throughout the rest of the pages through the global and root styles. 
- Created a header, nav, and footer to be shared by each page. 
- Created a complete home page with internal links to other pages of the website.
